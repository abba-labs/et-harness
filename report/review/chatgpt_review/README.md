## 工作边界

用户说明现有 IP 已通过测试。本轮按保持既有覆盖和行为的目标提出方案，不将历史通过结论直接视为改动后通过。

Case 的设备操作只调用 Driver；Driver 定义命令，不反向依赖 Case，不承担最终 PASS/FAIL。公共字段比较仍在 Case 层，记录函数只保存已读数据。先从 CAN 的 ECC 复杂 Case 建立可读样板，其他 IP 留待后续批次。

预览中的 `CanDriver.state_reset()` 尚未实现，是唯一拟新增的设备 API。它需要先完成固件、协议和隔离验证；当前预览不是可直接替换的已验证代码。

报告备注只显示 FAIL 的失败项，PASS 留空；其他状态仍保留各自状态和原始原因。原始结果、日志与 Observation 不因备注精简而删除。

CAN 状态复位、ECC Case 可读性和公共报告备注各为独立逻辑批次。本轮只提交本任务目录中的 Markdown，不改运行代码，也没有新增 CAN/HIL 通过结论。
