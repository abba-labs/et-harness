## 问题：APB1 Divider 切换后 Counter 速率比不足 1.5

现象：CRG 读回 source 全为 APB1，divider 样本为 `[0,0,0,0,1,1,1,1]`。两档 Counter 均在走（delta>0），但中位速率几乎不变：

- divider=0 速率 `12517351.89`
- divider=1 速率 `12492141.94`
- 速率比 `1.002018`（要求 `>= 1.5`）

断言：`assert rate_ratio >= WDG_CLOCK_MIN_RATE_RATIO` 失败。

证据指针：Observation `CRG.WDG_CLOCK_SOURCE` / `CRG.WDG_CLOCK_DIVIDER` / `COUNTER.CURRENT` 四轮 before/after 样本。Measurement `counter_rate_ratio=1.0020180648864887`。

未关闭问题：当前 FPGA WDG Counter 速率未随 APB1 Divider 0→1（SVD 编码 /1 与 /2）产生可接受变化。CRG 配置读回正确只是必要条件，不得放宽 1.5 倍阈值或删除断言。

适用条件：ET6801 / FPGA / `7106a1562269da95d060e2cd756d53eef7e156d4` / source_dirty=true / `et6801-silicon-common-v0.1` / 无参数。bitstream/设备身份未知。

已试过 / 还缺：本轮数字与 2026-08-28 状态块（比约 0.993）同类。已知 SDK `CRG_getWDGClock()` getter 有 Driver Bug，本 Case 不用该 getter 自证。还缺 RTL/bit 确认真实时钟路径后复测。
