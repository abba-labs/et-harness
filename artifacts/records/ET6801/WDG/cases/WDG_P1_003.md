# WDG_P1_003 — WDG轮次工作模式测试

整理时间：2026-09-15；对照本轮 Canonical Session 更新，不是新增测试。

适用基线：ET6801 / FPGA（单核 Profile `et6801_fpga`）；源码版本 `546c3a2` 之后的修正提交，固件 `et6801-silicon-common-v0.1`；bitstream/设备身份未知。不把本轮 FPGA 结果写成 Silicon 结论。

## 结论：模式0在此FPGA上不产生第二轮复位，复位判据改由同轮模式承担

实测：`ROUND1_IRQ_ROUND2_RESET` 第一轮 IRQ 正常到达并留下 interrupt record，但第二轮
复位未出现（`RequestTimeout: target did not disconnect`）。厂商 `WDG_15` 用该模式时
同样没有启用 reset 输出，其代码注释的 "system reboot" 用 `ET_TC_CHECK_BOOL_EQ(true, true)`
（永真）断言，未真实验证过第二轮复位。

RTL 补充事实：`int_reload_req` 在清中断（`cfg_int_clr`）时重载计数器，而 `rst_req`
要求 `cur_val == 0`；使用 IRQ 源的路径很难让计数器走到 0。

修正：模式0 只取证第一轮在线 IRQ 与 interrupt record，不再宣称复位；系统复位判据改由
`SAME_ROUND_IRQ_RESET` 承担（使能后第一次自然到期即复位，无需第二轮）。

本轮 FPGA 实测 PASS：模式0 首轮 IRQ 与中断记录正确、无 reset record；同轮模式重连后
interrupt/reset 两类记录均置位并可精确清除。
