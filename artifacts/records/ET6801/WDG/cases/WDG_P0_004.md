# WDG_P0_004 — WDG真实超时复位与跨重启取证测试

整理时间：2026-09-15；对照本轮 Canonical Session 更新，不是新增测试。

适用基线：ET6801 / FPGA（单核 Profile `et6801_fpga`）；源码版本 `546c3a2` 之后的修正提交，固件 `et6801-silicon-common-v0.1`；bitstream/设备身份未知。不把本轮 FPGA 结果写成 Silicon 结论。

## 结论：原FAIL是刺激方法缺IRQ使能，已修正并PASS

原因：`ROUND1_IRQ_ROUND2_RESET`（`WdgConfig` 默认work_mode）需要第一轮中断事件推进；Case 只开 reset 输出却从未使能 timeout IRQ 源，第一轮不产生事件，第二轮 reset 永不到来。手动诊断在 ET6801 FPGA 上确认：加 `WDG_enableInterrupt` 即复位，不加则不复位。

修正：武装前先 `irq_clear/irq_unmask/irq_enable`，并把 work_mode 显式设为 `SAME_ROUND_IRQ_RESET`；RTL 的 `int_reload_req` 会在清中断（`cfg_int_clr`）时重载计数器，使计数器到不了 0，因此系统复位判据由同轮模式承担。

本轮 FPGA 实测 PASS：出现预期断线、重连后目标 RECORD.RESET 置位、对照保持 0、清除后复读为 0。
