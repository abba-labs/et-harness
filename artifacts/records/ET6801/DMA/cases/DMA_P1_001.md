# DMA_P1_001 — DMA全部可用Channel原子并发启动与独立数据一致性测试

整理时间：2026-09-11 21:00 CST；对照本轮 Canonical Session 更新，不是新增测试。

适用基线：ET6801 / FPGA（单核 Profile `et6801_fpga`）；本轮 2026-09-11 20:31 CST，源码 `095cd6dba09dfee2d135f74bc913ad065ec9d6bb`（source_dirty=false，clean）；固件 `et6801-silicon-common-v0.1`；bitstream/设备身份未知。不把本轮 FPGA 结果写成 Silicon 结论。

## 结果与可复用经验

历史运行（2026-08-10冻结全量HIL、2026-08-13 UART+DMA观测HIL、2026-08-28 DMA全量28/28 PASS）中DMA无FAIL记录，本Case为PASS；参数级明细不可考，本文不引用观测值。方法：读取Runtime Channel Count并逐Channel确认M2M能力；为每个Channel准备独立Source/Destination与互不相同的Payload；Enable Controller并逐Channel Configure后，一次CHANNELS_START提交覆盖全部Runtime Channel的完整Mask；逐Channel有界等待FREE后读取全部Destination与状态并汇总判定。

## 复测要点与判断边界

- 判定：Runtime全部Channel进入同一启动Mask；每Channel数据无串扰且各自匹配其独立Payload；全部Channel最终FREE=1。
- 边界："一次原子启动"是本Case核心——分多次启动即退化为逐通道测试，并发语义未被覆盖；Mask必须恰好等于Channel全集，多余bit或缺失bit都算配置污染。
- 判断边界提醒：启动Mask作为Expected/Actual双份取证（oracle与dut_config分源）；并发下每个Channel的Buffer与Payload必须独立，避免共享内存掩盖串扰。
